# Drive-knup-im602-para-MacOS-2026-
Driver para usar a impressora térmica Knup KP-IM602 (80 mm, USB) no Mac. Imprime recibos e pedidos com o mesmo layout do Windows, com corte automático. Funciona em Apple Silicon e Intel.

Primeira versão do driver da Knup KP-IM602 para Mac.

Como instalar:
1. Ligue a impressora e conecte o cabo USB.
2. Baixe o arquivo Knup-IM602-Mac-1.0.0.pkg aqui embaixo, em "Assets".
3. Dê dois cliques e siga o instalador.

Se o Mac bloquear o instalador, vá em Ajustes do Sistema → Privacidade e Segurança → "Abrir mesmo assim".

O que tem nesta versão:
- Impressão com o mesmo layout da tela (Chrome, Safari, PDF, FacilZap, VendiZap)
- Corte automático do papel
- Remove o espaço em branco do fim do recibo
- Corrige o espaçamento vertical que a IM602 encolhia
- Opções: escuridão, modo texto/foto, gaveta e bipe
